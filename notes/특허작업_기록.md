## 3. 볼트 규칙 파일 수정 검토 (2026-11-21 06:15 수정분)

### 3.1 수정 내용

- 대상 파일은 볼트의 `특허\00_기준\00_명세서작업_주의점.md`이다.

### 3.2 판단

- 판단은 부분 적절이다.
- 대체 구현별 판정 기준, 검사 결과의 구분 기록, 축약률 목표로 핵심 작동을 지우지 않는 규칙, 공개 코드의 선택 모드 대비는 타당하다.

## 4. 볼트 편집 권한 확인 (2026-11-21)

### 4.1 확인 결과

- 볼트 파일은 Google Drive의 「내 Mac」 폴더 아래에 있다. 이 폴더는 Drive 데스크톱 앱의 컴퓨터 동기화 영역이다.
- 커넥터는 이 영역의 파일과 폴더를 모두 `canEdit: false`로 보고한다.
- Remote Control로 연결할 수 있는 Mac 폴더는 0개이다.

### 4.2 볼트를 직접 고치는 방법

- 가. 볼트를 그대로 두는 방법: Drive 환경설정의 「내 Mac」 탭에서 `Obsidian Vault` 항목이 「Google Drive와 동기화」로 되어 있는지 확인한다. 그 뒤 클라우드 세션에서 `canEdit` 값이 바뀌었는지 다시 확인한다.
- 나. Remote Control 연결: Mac의 Claude 데스크톱 앱에서 설정 → Claude Code → Remote Control에 볼트 폴더를 추가한다.
- 다. 「내 드라이브」 미러링으로 옮기는 방법: 볼트를 Google Drive 폴더 안으로 옮겨야 하므로 「기존 볼트를 그대로 둔다」는 조건을 지킬 수 없다. 옮기면 Obsidian 설정, 스킬·스크립트, 예약 작업 `patent-download-watch`에 적힌 경로를 모두 고쳐야 한다.
- 권하는 순서는 가 → 나 → 다이다.
