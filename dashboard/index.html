    이 화면의 수치는 브라우저 안에서 재현한 모델이 만든 시뮬레이션 데이터다. 문맥 채점(앞뒤 각 60자, 점수비 1.3), 끈의 베지어 곡선(처짐 계수 0.15), 가장자리 표시 위치(여백 12px), 폴링 주기(150ms)는 StringConnect.Core의 AnchorMatcher, StringGeometry, EdgeIndicatorCalculator와 ConnectionPollingService의 규칙을 그대로 옮겨 계산한다. 폴링 소요시간은 UI Automation 재조회 비용을 창 수와 앵커 수로 근사한 추정값이다.
